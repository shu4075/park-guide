# ネタ投稿フォームの作り方（Googleフォーム）

利用者からのBGS・小ネタ・隠れミッキーの投稿は、Googleフォームで受け付ける。
投稿はすぐには載せず、開発者が事実を確かめてから `spots.js` に自分の言葉で書いて追加する。

## いちばん簡単な作り方（スクリプトで自動）

[create-form.gs](create-form.gs) を Google Apps Script で実行すると、下の質問がそろったフォームが自動でできる。
手順はファイルの先頭に書いてある。できた「回答用URL」を `app.js` の `SUBMIT_FORM_URL` に貼る。

## 手で作る場合

1. https://forms.google.com で「空白のフォーム」を作る
2. タイトル：「パークさんぽガイド ネタ投稿」
3. 説明文に、次の注意を書く
   - 本や他のサイトの文章を写さず、自分の言葉で書いてください
   - どこで知ったか（出典）を書いてください
   - 写真は自分で撮ったものだけにしてください
   - 内容を確かめてから掲載します。掲載しないこともあります
4. 下の質問を追加する
5. 右上の「送信」→ リンクのマーク →「URLを短縮」→ コピー
6. `app.js` の上のほうにある `SUBMIT_FORM_URL = ""` の `""` の中に貼る
   → 一覧画面の「投稿フォームを開く」ボタンが表示されるようになる

## 質問

| 質問 | 形式 | 必須 |
|---|---|---|
| 種類（BGS／小ネタ／隠れミッキー） | ラジオボタン | ○ |
| 場所（エリア名、アトラクション名、目印など） | 記述式 | ○ |
| 内容 | 段落 | ○ |
| 出典（公式サイトのページ、ガイドツアー、自分で見つけた など） | 段落 | ○ |
| 公式設定か、自分やファンの考察か | ラジオボタン（公式設定／考察・諸説あり／わからない） | ○ |
| 写真のURL（任意。Googleドライブなどで共有したもの） | 記述式 | |
| 掲載するときの名前（任意。出典として表示する場合あり） | 記述式 | |
| 上の注意を読みました | チェックボックス | ○ |

## メモ

- Googleフォームの「ファイルのアップロード」を使うと、投稿者にGoogleへのログインが必要になる。
  気軽に投稿してもらうため、写真はURLで受け取る形にしている
- 届いた投稿は、フォームの「回答」タブでスプレッドシートにまとめて見られる
- 他の人が見つけた隠れミッキーや独自の考察を載せるときは、企画書のルールどおり出典を書く
