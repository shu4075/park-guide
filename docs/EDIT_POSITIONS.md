# スポットの位置の直し方

スポットの位置（緯度・経度）と反応する半径は、`spots.js` に書いてある。
直し方は「① パークでアプリを使って直す → ② spots.js に書き写す」の2段階。

## ① パークで直す（位置編集モード）

1. アプリ画面の一番下にある「**位置編集**」を押す
2. 地図の上に、スポットごとに朱色の「◎」が出る
3. 直し方は3つ
   - **ドラッグ**：◎ を指で押さえたまま、正しい場所まで動かす
   - **今いる場所にする**：GPSモードにして、スポットの場所に立つ。◎ をタップして選び、「今いる場所にする」を押す（いちばん正確）
   - **半径**：◎ をタップして選び、「半径 −5m／＋5m」で、反応する範囲の円の大きさを変える
4. 間違えたら「元に戻す」で、spots.js に書いてある値に戻る
5. 終わったら「終わる」

コツ
- 「今いる場所にする」の前に「デバッグ」をONにして、誤差を見る。誤差が大きい（黄色）ときは、少し待つか、開けた場所で押す
- 直した位置は、そのスマホにすぐ反映される（アプリを開き直しても残る）。ほかの人の画面には、② をするまで反映されない

## ② spots.js に書き写す

1. 位置編集モードで「**直した内容をコピー**」を押す。次のような文字がコピーされる

   ```
   // カリブの海賊（id: "pirates"）
       lat: 35.63475,
       lng: 139.881422,
       radius: 50,
   ```

2. 書き写す方法は、どれでもよい
   - **Claude に貼る**：「位置を直したので反映して」と書いて、コピーした文字を貼る（いちばん簡単）
   - **スマホやPCのブラウザで GitHub を直接直す**：
     1. https://github.com/shu4075/park-guide/blob/main/spots.js を開く
     2. 右上の鉛筆マーク（Edit this file）を押す
     3. コピーした文字の `id` と同じスポットを探し、`lat:` `lng:` `radius:` の数字を書き換える
     4. 右上の「Commit changes...」→ もう一度「Commit changes」
     5. 1〜2分で公開サイトに反映される
   - **VS Code で直す**：`spots.js` を開いて同じように書き換え、コミットして `git push`

3. spots.js が書き換わったスマホでは、端末に保存されていた直しは自動で消える（二重に直されることはない）

## 位置を Googleマップで調べる場合

家で直すときは、Googleマップで場所を右クリック（スマホは長押し）すると、
`35.63475, 139.881422` のような数字が出る。前が `lat`（緯度）、後ろが `lng`（経度）。
